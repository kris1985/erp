# 可执行 OKR：路线图「已有 / 补齐 / 不做」

> **源文件：** [`product-roadmap.md`](./product-roadmap.md)（优先级总源；冲突以总纲为准）  
> **口径：**  
> - **已有** = 主路径可演示 / 已验收，可对外讲  
> - **补齐** = 本阶段仍要做完才算闭环（或走查/体验债）  
> - **不做** = 本 ID / 本阶段明确禁区（含 P∞）  
> **用法：** 每个迭代只从「补齐」列抽 KR；「不做」列售前与排期双检。

---

## 9. 轨 B 硬序（补齐时不可颠倒）

```text
B0 流转卡/齐码发货     ← 已有
  → B1 按码 L1+L2      ← 已有
    → P2-Must 外发+箱唛 ← 补齐（当前）
      → P2-Next 合批    ← 其后
        → P3 真合单     ← 闸门后
```
