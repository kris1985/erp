## 4. 全生命周期（主内容区）

> 区块标题：**从接单到回款，风险在途中截断**  
> 副文：风险会顺着链路传导。月底爆发，往往是上游没拦住的结果。

| 环节 | 当天管什么 | 不把什么堆到月底 |
|------|------------|------------------|
| **接单** | 毛利、缺料、争料、交期冲击一眼齐 | 接完才发现亏 / 挤单 |
| **齐套** | 缺料清单、预计齐套日、争料谁跟谁抢 | 开工才喊没料 |
| **排产** | 插单先看冲击谁，生管确认再落库 | Excel 改到深夜 |
| **报工** | 扫码 / 过站当天进账，进度跟着走 | 群里追问做到哪、月底才发现漏报 |
| **工资** | 报工锁价进计件，异常行提前亮 | 月底对表吵架、会计熬夜 |
| **出货** | 齐码可发闸门 + 装箱箱唛 | 短码错箱、客诉堆到月底 |
| **财务侧** | 回款风险提前看，业务数先算清 | 放货后才发现坏账；两套数对不齐 |

**环节下金句（可轮播 / 角标）**

- 齐套不是感觉，是占用后的结论。
- 插单先看挤谁，再决定接不接。
- 扫了就能算钱；异常先亮，月结出稿。
- 出货有闸门，箱唛有主路径。
- 业务先算清，财务好对接。

| **进度日报** | 产量 KPI + 重点订单，每天同步一次心跳 |

**小字**  
只推不改：不自动改单、不改齐套、不改排产。推送失败也不阻断主业务。

## 6. 像鞋厂的闭环（功能信任区）

> 区块标题：**先像鞋厂，再有参谋**  
> 副文：顾问验货先看单据；老板买单再看拍板与预警。

主链路（可做成横向步骤）：

```text
接单拍板 → 按码算料 / 齐套争料 → 流转卡开裁 → 扫码报工 / 计件
    → 排产方案确认 → 齐码可发 / 装箱箱唛 → 不良返修 / 品质追溯
```

短句三连：

- **像鞋厂**：流转卡、按码算料、齐码出货、装箱箱唛、变更、IQC / 追溯
- **能拍板**：接单先看毛利、缺料、交期冲击与争料；排产插单先看挤谁
- **敢用人**：AI 只做参谋；确认生产、确认排产、改单改价必须人点

## 10. FAQ（折叠区短答）

> 口径对齐系统交付与边界：能讲的讲清，规划中 / 明确不做的不超卖。  
> 官网可按分组折叠；销售口播可整表背。

### 10.1 定位与对标

| 问 | 答 |
|----|----|
| 你们是什么系统？ | 生产执行型鞋业 ERP：接单能拍板、齐套不打架、计件能算清、排产能确认。 |
| 和用友 / 金蝶比？ | 不拼总账税务；拼接单拍板、齐套、报工计件、可确认排产。财务可对接，不是小号用友。 |
| 和某某鞋业 ERP 比？ | 流转卡、按码算料、装箱箱唛、齐码出货等单据闭环我们对齐验货；多出来的是接单决策、争料互斥、插单冲击、军师解释与当天预警。 |
| 和「只卖 AI」方案比？ | 不是外挂聊天机器人。账本在本 ERP，预警与参谋嵌在链路里；关掉 AI，主路径仍能拍板。 |
| 适合什么样的厂？ | 成鞋 OEM / 外贸鞋厂：有接单拍板、齐套争料、报工计件、交期管控诉求的中小到中型厂。 |
| 鞋底厂 / 造粒排模行吗？ | 不是主战场。一期面向成鞋组装执行链，不做鞋底专版。 |
| 品牌分销 / 订货会有吗？ | 不做。主战场是 OEM 生产执行，不是品牌分销。 |
| 能替代金蝶做账吗？ | 不能、也不做。我们算清业务侧（毛利、回款风险、计件、出货），总账税务走对接或现有财务软件。 |

### 10.2 接单与经营拍板

| 问 | 答 |
|----|----|
| 接单怎么拍板？ | 销售单打开就能看毛利粗估、缺料、争料、交期冲击、色码偏离、回款标签；改数量 / 交期假设可重算，人再决定接不接。 |
| 接单还要等月底报表吗？ | 不用。接单当下就能看经营与产能冲击，不是等月底出表。 |
| 两单抢同一块料怎么办？ | 池库存分配互斥：不能两单同时假装齐套；争料谁跟谁抢看得见，再决定保急单还是让单。 |
| 色码开乱了怎么办？ | 接单可看本单色码曲线相对历史的偏离提示，谈单时就能改码，减少尾码积压。 |
| 报价能自动发给客户吗？ | 不会自动对客发价。可看成本卡与同类款实绩区间，人确认后再出价。 |
| 客户拖款风险怎么看？ | 接单有回款风险标签；毛利好看不等于放得心安。完整放货门禁可按厂再加严。 |

### 10.3 齐套、缺料、采购催办

| 问 | 答 |
|----|----|
| 齐套怎么算？ | BOM × 库存 × 在途 × 承诺占用，规则引擎算；预计齐套日可喂排产最早开工。 |
| 缺料谁先催？ | 缺料清单带预计齐套日 / 风险；可批量导出 Excel，也可推进企微 / 钉钉催采购跟单。 |
| 按码算料有吗？ | 有。关键料可配按码用量，齐套 / 采购按码汇总；非关键料仍可按总双。 |
| 会不会两单都显示「料齐了」？ | 不会。池分配互斥，齐套结论写在账本上，不是写在微信里。 |
| AI 会自动下采购单吗？ | 不会。给缺料与建议清单，人确认后执行。 |
| 客供料怎么管？ | 有客供标记与成本规则；客供收货台可按厂深化，一期不拿「客供全闭环」超卖。 |

### 10.4 排产与插单

| 问 | 答 |
|----|----|
| 排产是全自动吗？ | 不是。系统出可对比方案，生管微调后确认落库——可解释、可确认，不是无人 APS。 |
| 急单插进来怎么办？ | 先仿真冲击：看挤谁、 defer 谁，再决定接不接、怎么插。 |
| 比 Excel 强在哪？ | 方案可对比、插单有冲击、确认才落库；比百万级 APS 轻，比纯 Excel 可控。 |
| 有甘特图拖拽排产吗？ | 近端不做机台级甘特拖拽。做的是工序产能 + 方案对比 + 插单 HITL。 |
| 产能不准怎么办？ | 可在排产设置填日产能，接单也可设假设日产能；后续可用报工真值校准。 |
| 厂休 / 停电怎么跳过？ | 支持租户停工日与计划日历旋钮，排产算工作日时跳过。 |

### 10.5 报工、流转卡、计件工资

| 问 | 答 |
|----|----|
| 现场怎么开裁？ | 生产单一键打流转卡（色码 × 工序），裁床 / 组长认同一张纸。 |
| 报工怎么做？ | 扫码 / 捆标过站报工；进度跟着报工走，不是月底翻表才知道做到哪。 |
| 工资怎么算？ | 报工锁价进计件，月结出稿；扫了就能算钱。 |
| 月底工资还要对 Excel 吗？ | 目标是月结出稿、异常先核对。计件异常可高亮例外行，不靠肉眼抠整张表。 |
| 计件异常会改工资引擎吗？ | 不会。异常是只读高亮复核，不重做工资引擎、不偷偷改口径。 |
| 奖惩请假进工资吗？ | 模型已定，实现按排期；售前勿承诺「人事全模块已齐」。 |
| 能防止代报 / 空转报工吗？ | 工位扫码已有；更严的上道完工闸门、派工挂工位可按厂加严，默认先跑得通。 |
| 合刀 / 合批后工资怎么认？ | 合批阶段领料 / 报工 / 出货仍认生产单（合批不合单），账本不糊。 |

### 10.6 出货、齐码、装箱箱唛

| 问 | 答 |
|----|----|
| 未齐码能出货吗？ | 默认拦。可发量按约定工序合格 − 已出；未齐码确认出货会拦截。 |
| 箱唛有吗？ | 有主路径：装箱计划 → 箱唛打印（含箱号码）→ 可选验箱拦错码 / 超箱。 |
| 配码装箱支持吗？ | 支持按色码做单码 / 混码装箱计划，减少跟单在 Excel 里熬夜。 |
| 出货认销售单还是生产单？ | 出货认生产单；有销售行时经 1∶1 回写销售。合批阶段不假装合单出货。 |
| 完整仓库 WMS 有吗？ | 明确不做完整 WMS / 货位盘点。池库存 + 出货闸门够用；要货位可对接或极后。 |

### 10.7 品质、变更、追溯

| 问 | 答 |
|----|----|
| 来料不良怎么拦？ | 来料 IQC：检验 / 让步后再入池，避免坏料当齐套。 |
| 不良怎么返修？ | 不良登记可派返修；个人返修报工有主路径。集体返修政策前不做。 |
| 客诉能追溯吗？ | 可按捆标 / 过站反查责任线索，从事后翻纸变成可追。 |
| 品质预警有吗？ | 有。按款 × 工序不良率相对均值突增，给出抽检建议，不必等出货 / 客诉才发现。 |
| 改单有版本吗？ | 有变更历史：谁、何时、改了什么、改前改后，减少改单扯皮。 |
| 同款多单能合刀吗？ | 支持合批组批 + 合批流转卡；领料 / 报工 / 出货仍分生产单。真「一指令多订单」须另认领升级，不无分配硬合并。 |

### 10.8 预警、日报、IM 推送

| 问 | 答 |
|----|----|
| 预警推什么？ | 缺料、交期风险；另可开进度日报（产量 KPI + 重点订单）。 |
| 推到哪里？ | 企微 / 钉钉群机器人 Webhook；租户可配地址、总开关与事件子项。 |
| 必须天天开系统吗？ | 不必。异常与日报可推进群，老板 / PMC 在手机群里就能看见。 |
| 预警会不会乱改单？ | 不会。只推不改；推送失败也不阻断主业务。 |
| 口径会不会跟系统两套？ | 不会。预警与进度日报跟车间看板同源，群里和系统说的是同一套数。 |
| 只有坏消息吗？ | 不是。缺料 / 交期是打断；进度日报是日常心跳，避免只有报警导致麻木。 |
| 能 @ 到具体人吗？ | v1 走群机器人摘要推送；企业级应用凭证、签名、@人属后续增强，不拿来当入门承诺。 |
| 缺料还能导出吗？ | 能。缺料可批量导出 Excel，并可走同一 Webhook 通道催办。 |

### 10.9 智能 Agent / 军师

| 问 | 答 |
|----|----|
| 是不是必须上 AI？ | 不是。单据闭环与规则诊断是主路径；军师是解释与追问，可关。 |
| AI 会不会改错单？ | 不会。Agent 出建议 / 预警 / 草稿；改数量、交期、排产、导入落库必须人工确认。 |
| 军师能问什么？ | 如「A 客户做到哪了」「缺什么料」——白名单工具只查不改，不是闲聊 ChatGPT。 |
| 交期 / 金额是 AI 算的吗？ | 不是。齐套、库存、工资、利润走确定性规则引擎；大模型只做理解问题与生成说明。 |
| 「今日 3 件事」是什么？ | 每天最多 3 条可执行行动（催料 / 保交期 / 可排），带单号证据，一点可跳进落地页。 |
| 要私有化大模型吗？ | 不默认。账本在本地，模型按需调用并脱敏；不为中小厂强推私有化模型。 |
| 能不能先上 OCR 证明 AI？ | 单据 OCR 初稿可规划；但证明价值更快的是齐套、排产插单、计件和接单面——现成可演示。 |
| AI 会自动排版裁断吗？ | 不做 AI 裁断排版、全线视觉质检硬件作为入门门槛。 |

### 10.10 财务与经营数字

| 问 | 答 |
|----|----|
| 有应收 / 利润吗？ | 有经营侧的毛利粗估、回款风险、利润相关能力；不是完整总账。 |
| 财务怎么对接？ | 业务先算清，再导出 / 对接财务软件；我们不做凭证、期间、税务替代。 |
| 实耗和成本卡差很多怎么办？ | 接单 / 批价侧可看同类款实绩与损耗对比；超标可进今日行动，人再决策。 |
| 出货后坏账怎么防？ | 接单先看回款标签；放货提示可增强。不是贷后催收系统。 |

### 10.11 使用方式、权限、实施

| 问 | 答 |
|----|----|
