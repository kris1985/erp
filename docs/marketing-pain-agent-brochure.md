# 鞋厂痛点 × 智能 Agent — 产品宣传文案

> **用途**：官网落地页、产品宣传册、销售一页纸、展会展板。  
> **叙事顺序（定稿）**：**先讲功能闭环（像鞋厂）→ 再讲智能 Agent（多出来的参谋）**。顾问验货先看单据；老板买单再看拍板与 AI。  
> **口径**：对外可称「智能 Agent / 军师」；对内仍是「规则引擎算数 + AI 解释 + 人确认」。  
> **原则**：不承诺 AI 自动改账本、不承诺全自动无人排产、不拼用友/金蝶总账。  
> **产品定位（对外一句话）**：生产执行型鞋业 ERP —— 接单能拍板、齐套不打架、计件能算清、排产能确认。  
> **竞品依据：** [`competitive-scoring-footwear-erp.md`](./competitive-scoring-footwear-erp.md) · [`competitive-gap-footwear-erp.md`](./competitive-gap-footwear-erp.md)  
> **路线图 / Agent OKR：** [`product-roadmap.md`](./product-roadmap.md) · [`okr-agent-capabilities.md`](./okr-agent-capabilities.md)

## 0. 对标怎么讲（销售先背这三段）

| 对手 | 怎么讲 |
|------|--------|
| **小牛 / 云管家 / 泛普** | 鞋厂单据我们按车间闭环补齐（流转卡、按码算料、装箱箱唛、齐码出货、变更、IQC/追溯）；**多出来的是接单拍板、齐套争料互斥、可确认排产、计件闭环、军师解释**。 |
| **用友 / 金蝶** | 不拼总账税务；拼接单、齐套、报工计件、排产确认。财务可对接，不是小号用友。 |
| **「只卖 AI」方案** | 我们不是外挂聊天机器人：账本在本 ERP，Agent 嵌在链路里；关掉 AI，主路径仍能拍板。 |

**一句话收口**  
先把鞋厂该有的闭环跑通，再用 Agent 帮你少吼、少对 Excel、少拍脑袋——**AI 给建议，账本听人的。**

**色码算料 → 齐套争料 → 流转卡报工 → 排产确认 → 装箱出货 → 计件追溯**，一条可确认的链路。  
智能 Agent 嵌在链路里做扫描、预警与解释；**数量、交期、金额，始终由人确认。**

## 2. 上篇 · 功能闭环（先讲清楚「系统会干什么」）

> 版式建议：一条横向主链路 + 六～八张闭环卡。每张卡只写：**痛点 → 闭环怎么走 → 你得到什么**。  
> **不要在这页堆 Agent 名词**——先让厂长觉得「像我们厂」。

### 2.1 主链路一览（可印成一张图）

```text
接单拍板 → 按码算料 / 齐套争料 → 流转卡开裁 → 扫码报工 / 计件
    → 排产方案确认 → 齐码可发 / 装箱箱唛 → 不良返修 / 品质追溯
```

| 环节 | 一句话功能 | 闭环终点 |
|------|------------|----------|
| 接单 | 打开销售单看毛利粗估、缺料、争料、交期冲击 | 人决定接不接、怎么改码 |
| 算料齐套 | 按码用量进需求；池库存承诺互斥；预计齐套日 | 催料有单号，不开「口头齐套」 |
| 开裁现场 | 生产单流转卡一键打印（色码×工序） | 裁床/组长认同一张纸 |
| 报工计件 | 扫码/过站报工，锁价进月结 | 扫了就能算钱 |
| 排产 | 正排/倒排出方案，插单先仿真冲击 | 生管确认后落库 |
| 出货 | 齐码可发闸门 + 配码装箱 + 箱唛（可验箱） | 未齐码拦得住，箱唛打得出 |
| 质量 | 来料 IQC、不良→返修、捆标追溯 | 投诉能反查线索 |
| 变更 / 合批 | 变更留版本；同款可组批打合批卡（领料仍分单） | 改单可追、合刀有纸 |

### 2.2 闭环卡片（官网主区 · 功能向）

#### F1 · 接单决策面（不是报表，是拍板页）

**厂里怎么吵**  
「这单接不接？会不会亏？会不会挤别人交期？」

**闭环**  
销售单打开 → 左栏即时给出毛利粗估、缺料、争料、色码偏离、回款标签 → 改数量/交期假设可重算 → **人确认是否接单 / 建生产单**。

**你得到什么**  
接单不靠拍脑袋，也不等月底出报表。

---

#### F2 · 按码算料 + 齐套争料

**厂里怎么吵**  
「料齐了没有？」「按总双采购，码不对、尾码欠。」「两单抢同一底料，都说自己齐套。」

**闭环**  
BOM 可标按码用量 → 需求/齐套/采购按码汇总 → 池库存分配**互斥**（不能两单同时假装齐套）→ 缺料清单 + 预计齐套日 → 催料跳到具体单。

**你得到什么**  
齐套结论写在账本上，不再写在微信里。

---

#### F3 · 流转卡 + 扫码报工 + 计件

**厂里怎么吵**  
「开裁靠吼」「做到哪了群里问」「工资月底对 Excel」。

**闭环**  
生产单打印流转卡 → 现场扫码/捆标过站报工 → 单价锁进计件 → 月结出稿；异常行可核对。

**你得到什么**  
纸面能开裁，扫了能算钱——相对多数通用 ERP 更贴车间。

---

#### F4 · 排产方案 + 插单确认

**厂里怎么吵**  
「排产靠 Excel，急单一插整表作废。」

**闭环**  
按产能、齐套日、交期出可对比方案 → 插单先列出冲击谁 → 生管微调 → **一键确认落库**（不自动偷改）。

**你得到什么**  
从「改到深夜」变成「看方案、点确认」。比百万级 APS 轻，比纯 Excel 可控。

---

#### F5 · 齐码出货 + 装箱箱唛

**厂里怎么吵**  
「未齐码就出了」「客户要箱单箱唛，跟单在 Excel 里熬夜」。

**闭环**  
可发量 = 约定工序合格 − 已出 → 确认出货未齐则拦截 → 按色码做单码/混码装箱计划 → 打印箱唛（含箱号码）→ 可选验箱拦错码/超箱。

**你得到什么**  
出货有闸门，箱唛有主路径。（对标垂直验收项；深度可按厂再加严。）

---

#### F6 · 品质：IQC · 返修 · 追溯

**厂里怎么吵**  
「坏料当齐套」「不良登了没人修」「投诉翻不到人」。

**闭环**  
来料检验/让步后再入池 → 不良登记派返修 → 捆标/过站反查责任线索。

**你得到什么**  
从事后翻纸，到入池可控、事后可追。

---

#### F7 · 变更版本 · 合批纸面（讲边界）

**厂里怎么吵**  
「改单扯皮没版本」「合刀靠 Excel，合了又怕出货乱」。

**闭环**  
变更单 + 历史版本可查；同款可组批并打合批流转卡——**领料/报工/出货仍认生产单**（合批不合单，账本不糊）。

**你得到什么**  
合刀有纸、出货不乱账；真「一指令多订单」需另行认领升级。

## 3. 下篇 · 智能 Agent（在闭环之上「多出来的」）

> 版式建议：先一句「垂直单据大家都会做，我们多参谋」；再核心 Agent 卡。  
> Agent = **规则自动化 + 数据汇总 + 异常提醒 + 可问可解释**；不是第二套系统。

### 3.1 Agent 总览表

| 厂里怎么吵 | 以前 | Agent | 叠在哪条闭环上 |
|------------|------|-------|----------------|
| 今天先催谁、保哪单 | 厂长靠吼 | **今日 3 件事** | 齐套 / 进度 / 交期 |
| 料齐了没有、谁跟采购对表 | 三方电话 | **齐套检查 Agent** | 算料齐套闭环 |
| 成型做到哪了 | 微信群 | **进度追踪 Agent** | 报工计件闭环 |
| 急单插进来整表废 | Excel 重排 | **智能排产 Agent** | 排产确认闭环 |
| 老板想问数不会点菜单 | 找人导出 | **自然语言问数** | 只读，叠全链路 |
| 皮料损耗心里没数 | 老师傅估 | **损耗对比 Agent** | 算料 / 领料 |
| 报价靠老师傅 | 经验拍 | **报价辅助 Agent** | 接单决策面 |
| 质量事后才知 | 灭火 | **品质预警 Agent** | IQC / 追溯 |
| 外发谁总拖 | Excel | **外协催收**（规划） | **先有外发单** |
| 客户发图表录到加班 | 手录 | **单据初稿 OCR**（规划） | 人确认后入账 |

### 3.2 核心 Agent 卡片（官网次屏 · 优先讲）

#### A1 · 今日 3 件事

**能力**  
每天最多 3 条可执行行动（催料 / 保交期 / 可排），带单号证据，一点跳进落地页。

**卖点**  
厂长打开系统，就知道今天先干什么——不是再翻一张总表。

**不夸大**  
不是第 4–N 条无限信息流；不依赖大模型编造 top3。

---

#### A2 · 齐套检查 Agent

**能力**  
自动比对 BOM × 库存 × 在途 × 承诺占用；缺料清单、建议采购量、预计齐套日；争料谁跟谁抢看得见。

**卖点**  
齐套参谋叠在互斥账本上，不是另做一张「假齐套表」。

**不夸大**  
不做 AI 自动下采购单。

---

#### A3 · 进度追踪 + 交期风险

**能力**  
报工实时汇总；订单风险条（红黄绿 + 原因）；可选企微/钉钉预警与进度日报（只推不改）。

**卖点**  
老板打开手机，就知道快了还是慢了。

**不夸大**  
不替代班组长现场管理。

---

#### A4 · 智能排产 Agent

**能力**  
综合订单、产能、齐套日与交期生成可对比方案；插单先仿真冲击；生管确认后落库。可问军师「为什么这样排」。

**卖点**  
排产从改 Excel，变成看方案、点确认。

**不夸大**  
不做黑盒全自动最优 APS。

---

#### A5 · 自然语言问数（军师）

**能力**  
「A 客户做到哪了」「缺什么料」——白名单工具只查不改；关掉 AI，看板仍能点到同一结论。

**卖点**  
说话就能查，查完不用怕改错账。

**不夸大**  
不是万能闲聊机器人；不做随意 NL2SQL 写库。

---

#### A6 · 报价辅助 · 损耗对比 · 品质预警 · 计件异常

| Agent | 一句话 | 不夸大 |
|-------|--------|--------|
| 报价辅助 | 成本卡 + 同类实绩区间，人确认后出价 | 不自动对客发价 |
| 损耗对比 | 标准损耗率 × 实耗，超标进今日行动 | 不做 AI 裁断排版 |
| 品质预警 | 抽检/加严建议提前进入今日行动 | 不做全线视觉硬件入门 |
| 计件异常 | 月结之上高亮例外行 | 不重做工资引擎 |

### 3.3 规划中 Agent（册内附录 · 必须绑单据）

| Agent | 前提 | 对外句 |
|-------|------|--------|
| 外协催收 / 厂评分 | **先有外发工序单** | 外发先有账，再有催和分 |
| 订单 / 来料 OCR 初稿 | 模板样本 + 人确认入库 | AI 出草稿，人点确认才进账 |

## 4. 价值叙事（可量化，但不写死销售数字）

| 场景 | 可讲的价值方向 | 验收怎么定（对内） |
|------|----------------|-------------------|
| 功能闭环跑通 | 少靠吼、少 Excel、现场认同一张纸 | 主路径演示：流转卡 / 齐套 / 箱唛 / 计件月结 |
| 齐套 / 缺料 | 少停线、少三方对表 | 缺料提前可见天数、催料闭环率 |
| 排产插单 | 生管从改表变为确认方案 | 出方案到确认时长、冲击可解释 |
| 计件 | 报工即可算钱 | 月结出稿时长、异常核对占比 |
| Agent 问数 / 今日行动 | 老板少找人导出 | 固定问法命中率；今日行动跳转 ≤3 步 |
| 单据初稿（增强） | 文员少加班录单 | 相对基线录单工时、差错率 |

**禁止写进官网绝对句：** 「减少 80% 工时」「错误率降 90%」——无该厂基线即视为噱头。

| AI 会不会改错单？ | 不会。Agent 出初稿/预警；改数量、交期、排产、导入落库必须人工确认。 |
| 是不是必须上 AI？ | 不是。规则诊断与单据闭环是主路径；AI 是解释与追问，可关。 |
| 要私有化大模型吗？ | 不默认。账本在本地，模型按需调用并脱敏。 |

## 9. 技术原则（官网「我们怎么做 AI」）

1. **先有单据与规则闭环，再叠 Agent。**  
2. **大模型用于理解问题与生成说明，不用于计算交期、数量与金额。**  
3. **齐套、库存、工资、利润记账走确定性规则引擎。**  
4. **排产与接单给出可解释方案，关键操作必须人工确认。**  
5. **Agent 嵌在本 ERP 内，不另建一套业务中台。**  
6. **不做 AI 裁断排版、全线视觉质检硬件作为入门门槛。**

```text
交互：ERP / 手机看板 / 企业微信·钉钉
  → 意图识别与军师编排（只调白名单工具）
  → 规则引擎（齐套·风险·排产·成本·损耗）+ 只读查询 / 草稿
  → ERP 账本（人工确认后写入）
```

AI 当参谋，拍板还是人。

## 11. 禁用话术（法务 / 售前自检）

| 不要说 | 改说 |
|--------|------|
| 全自动排产、无人值守 APS | 智能排产方案，生管确认后执行 |
| AI 自动改单、自动下采购 | 给出建议清单，人确认后执行 |
| 替代用友/金蝶财务总账 | 生产执行系统，财务可对接 |
| 外协智能管控已齐（无外发单时） | 外发单据规划中；有单后再做催收评分 |
| 百分百预测交期 / 不良 | 风险等级与预警建议 |
| 通用 ChatGPT 式闲聊助手 | 面向齐套、进度、交期、产量的生产参谋 |
| 减少 XX% 工时（无基线） | 相对贵厂上线前基线对比验收 |
| 外挂 AI 改造任意旧 ERP | 我们是生产执行 ERP，Agent 原生内嵌 |
| AI 自动排版 / 全线视觉已标配 | 规则损耗与追溯先落地；视觉属后期可选 |
