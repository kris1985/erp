# 鞋厂痛点 × 智能 Agent — 产品宣传文案

> **用途**：官网落地页、产品宣传册、销售一页纸、展会展板。  
> **口径**：对外可称「智能 Agent / 军师」；对内仍是「规则引擎算数 + AI 解释 + 人确认」。  
> **原则**：不承诺 AI 自动改账本、不承诺全自动无人排产、不拼用友/金蝶总账。  
> **产品定位（对外一句话）**：生产执行型鞋业 ERP —— 接单能拍板、齐套不打架、计件能算清、排产能确认。  
> **Agent 本质（对外可讲）**：规则自动化 + 数据自动汇总 + 异常智能提醒；AI 是工具，不是第二套系统。

## 1. 官网 / 册首主视觉文案

### 主标题（择一）

- **少靠吼，少对 Excel，多靠账本和参谋**
- **鞋厂每天吵的事，系统先算清楚，再让人拍板**
- **不是聊天机器人，是会干活的生产参谋**

### 副标题

面向 OEM / 外贸鞋厂的生产执行系统：把接单、齐套、报工、排产、追溯连成一条可确认的链路。  
智能 Agent **嵌在本系统内**，负责扫描、预警与解释；**关键数量、交期、金额，始终由人确认。**

### 三句价值主张（Hero 旁短句）

| 主张 | 展开 |
|------|------|
| 像鞋厂 | 色码、齐套、报工、排产、出货、外发/箱唛，按车间真实流程设计 |
| 能拍板 | 接单先看毛利、缺料、交期冲击与争料，再决定接不接 |
| 敢用人 | AI 只做参谋；确认生产、确认排产、改单改价必须人点 |

### 信任条（Hero 下方小字）

计算走规则引擎 · 问数走白名单工具 · 落库必须人工确认 · 关掉 AI 主路径仍可用 · 不做外挂第二套账本

## 2. 痛点 → Agent 能力（宣传册核心跨页）

> 版式建议：左栏「厂里怎么吵」，中栏「以前怎么扛」，右栏「现在怎么解决」。

### 总览表（可直接印）

| 厂里怎么吵 | 以前 | Agent / 能力 | 你得到什么 |
|------------|------|--------------|------------|
| 「这单接不接？会不会挤别人交期？」 | 凭感觉、翻旧表 | **接单决策参谋** | 打开订单即见毛利粗估、缺料、交期冲击、争料；假设改数秒级重算 |
| 「料齐了没有？谁在跟采购对 Excel？」 | 三方电话对账 | **齐套检查 Agent** | 自动比对 BOM × 库存 × 在途；缺料清单、建议采购量、预计齐套日 |
| 「成型做到哪了？群里问一圈」 | 微信群吼 | **进度追踪 Agent** | 报工实时汇总；计划 vs 完成、落后预警；可推企微/钉钉日报 |
| 「急单插进来，整张排程表作废」 | Excel 改到深夜 | **智能排产 Agent** | 按产能、齐套日、交期出方案；插单先仿真冲击，生管微调后确认 |
| 「皮料损耗心里没数，采购多买少买都亏」 | 老师傅估算 | **损耗对比 Agent** | 标准损耗率 × 实耗自动对比，超标预警，不搞昂贵 AI 排版 |
| 「客户投诉了，翻半天找哪批料谁做的」 | 纸质/散表 | **品质追溯 / 预警** | 捆标 + 过站 + 不良闭环；抽检建议提前加严 |
| 「报价靠老师傅，新人报不准」 | 经验拍脑袋 | **报价辅助 Agent** | 对照历史成本卡与同类款实绩，给出区间与依据，业务确认后出价 |
| 「老板想问数，不会点 ERP」 | 找人导出 | **自然语言问数** | 「A 客户做到哪了」「张三这个月多少双」——只查不改，返回结论 |
| 「外发收回对不上、谁家总拖」 | Excel 对账 | **外协催收 Agent** | 未回/超期提醒 + 良率周期评分（建立在外发单据之上） |
| 「客户发图/杂表，文员录到加班」 | 手工逐条录入 | **单据初稿 Agent** | OCR/表格解析生成导入草稿，异常高亮，**人确认后入账** |

### 核心场景（官网主卡片 · 优先讲）

#### 01 · 物料齐套检查 Agent

**痛点**  
采购、仓库、生管三方对账；口头说齐套，开裁才发现缺料停线。

**能力**  
接到订单后，自动比对 BOM 需求与库存、在途及承诺占用；输出缺料清单、建议采购量、预计齐套日期。

**一句话卖点**  
齐套结论写在账本上，不再写在微信里。

**对外可承诺**  
规则引擎实时扫描 · 争料互斥不「两单同时假装齐套」 · 催料有单号有证据  

**不夸大**  
不做「AI 自动下采购单」；采购确认仍由人。

---

#### 02 · 生产进度追踪 Agent

**痛点**  
「成型线做到哪了？」群里问一圈；异常发现晚，交期靠吼。

**能力**  
对接报工 / PDA 扫码，实时计算各工序进度与在制；计划对比完成，落后自动标红；可选推送企微/钉钉与生产进度日报。

**一句话卖点**  
老板打开手机，就知道车间是快了还是慢了。

**对外可承诺**  
报工即数据 · 订单风险一目了然 · 今日该催谁、该保谁有证据  

**不夸大**  
不替代班组长现场管理；推送通道按部署开通。

---

#### 03 · 自然语言查询（老板驾驶舱）

**痛点**  
培训成本高；老板只想问一句，不想学菜单。

**能力**  
在系统或企业 IM 中用自然语言查询产量、订单进度、缺料与交期风险；**只读查询，不改数据**。

**一句话卖点**  
说话就能查，查完不用怕改错账。

**对外可承诺**  
白名单指标与工具 · 禁止编造单号金额 · 关掉 AI 仍可从看板点进同一结论  

**不夸大**  
不是万能闲聊机器人；不做随意 NL2SQL 改库。

---

#### 04 · 智能排产 Agent

**痛点**  
生管 Excel 排产；插急单整表重排，改到崩溃。

**能力**  
综合订单、配置产能、物料齐套日与交期优先级，生成可对比的排产方案；插单先列出冲击对象，生管微调后一键确认。

**一句话卖点**  
排产从「改 Excel」变成「看方案、点确认」。

**对外可承诺**  
正排 / 倒排方案 · 插单冲击仿真 · 人机协同确认落库  

**不夸大**  
不做黑盒「全自动最优排程」；最终决定权在生管。

---

#### 05 · 品质异常预警 Agent

**痛点**  
不良登了才知道；事后灭火，客户投诉才翻记录。

**能力**  
不良登记与返修闭环；捆标追溯；基于统计的抽检/加严建议进入今日行动。

**一句话卖点**  
从事后翻纸，到事前加严、事后可追。

**对外可承诺**  
不良可闭环 · 追溯到捆 / 工序 / 责任线索  

**不夸大**  
首版以规则与统计预警为主；不做全线视觉质检硬件改造。

---

#### 06 · 智能报价辅助 Agent

**痛点**  
报价靠老师傅；新人慢、偏差大，响应客户慢。

**能力**  
匹配历史同类款与成本结构，对照材料、人工与实耗偏差，给出报价参考区间与依据；最终由业务确认。

**一句话卖点**  
新人也能报得快，老师傅审核有依据。

**对外可承诺**  
成本卡 + 历史实绩对照 · 区间报价 · 人确认后出价  

**不夸大**  
不自动对客户发价。

---

### 增强场景（官网次级 / 册内附录 · 讲清边界）

#### 07 · 损耗对比 Agent（皮料/关键料）

**痛点**  
真皮用量靠老师傅估算；多买积压、少买停线；裁断损耗月底才对得清。

**能力**  
按 BOM 与尺码配比核算理论用量；绑定材质标准损耗率；对比领料/报工实耗，超标预警并进今日行动。

**一句话卖点**  
用规则管损耗，不砸钱上 AI 排版机。

**不夸大**  
不做图像自动排版 / 裁断视觉改造。

---

#### 08 · 外协催收 Agent

**痛点**  
针车/复合外发，收回对不上、超期靠人催、哪家厂靠谱凭感觉。

**能力**  
在外发单据之上：未回数量、超期提醒、良率与周期评分表，辅助选厂。

**一句话卖点**  
外发先有账，再有催和分。

**不夸大**  
没有外发工序单，就不承诺「外协智能管控」。

---

#### 09 · 单据初稿 Agent（订单 / 来料 OCR）

**痛点**  
客户发 Excel/图片订单，文员手录易错；送货单月底对账通宵。

**能力**  
解析单据 → 匹配款号/采购单 → 生成 **导入草稿与差异清单** → 跟单/仓/财务确认后写入。

**一句话卖点**  
AI 出初稿，人点确认，账才进系统。

**不夸大**  
按客户模板适配推进；不承诺「任意格式零样本 100% 识别」。

---

#### 10 · 计件与成本异常核对

**痛点**  
月底对异常行耗时（返工扣减、单价例外）。

**能力**  
在已有计件月结之上，高亮异常行生成核对初稿；可选直接成本异常提示。

**一句话卖点**  
工资引擎已经会算；Agent 帮你盯住例外。

**不夸大**  
不重做一套工资或金蝶级费用分摊。

## 3. 价值叙事（可量化，但不写死销售数字）

> 对外用「方向性收益」；合同验收用「相对该厂基线」——上线前先量一周工时/差错/延期。

| 场景 | 可讲的价值方向 | 验收怎么定（对内） |
|------|----------------|-------------------|
| 齐套 / 缺料预警 | 少停线、少三方对 Excel | 缺料提前可见天数、催料闭环率 |
| 进度 / 交期预警 | 少靠群吼、异常更早暴露 | 预警提前量、延期单占比对比基线 |
| 排产插单 | 生管从改表变为确认方案 | 出方案到确认时长、插单冲击可解释 |
| 计件 | 报工即可算钱 | 月结出稿时长、异常行人工核对占比 |
| 单据初稿（增强） | 文员少加班录单 | 相对基线的录单工时、差错率 |
| 损耗对比（增强） | 采购估算更稳、超耗可见 | 实耗 vs 标准偏差分布、超标响应时长 |

**禁止写进官网绝对句：** 「减少 80% 工时」「错误率降 90%」「误差≤3%」——无该厂基线即视为噱头。

| 和用友/金蝶比？ | 我们不拼总账税务；拼接单拍板、齐套、计件、可确认排产。财务可对接。 |

## 8. 技术原则（官网「我们怎么做 AI」小节）

1. **大模型用于理解问题与生成说明，不用于计算交期、数量与金额。**  
2. **齐套、库存、工资、利润记账走确定性规则引擎。**  
3. **排产与接单给出可解释方案，关键操作必须人工确认。**  
4. **Agent 嵌在本 ERP 内，不另建一套业务中台。**  
5. **先把报工与单据录准；没有干净数据，再聪明的 Agent 也是摆设。**  
6. **不做 AI 裁断排版、全线视觉质检硬件作为入门门槛。**

```text
交互：ERP / 手机看板 / 企业微信·钉钉
  → 意图识别与军师编排（只调白名单工具）
  → 规则引擎（齐套·风险·排产·成本·损耗）+ 只读查询 / 草稿
  → ERP 账本（人工确认后写入）
```

## 10. 禁用话术（法务 / 售前自检）

| 不要说 | 改说 |
|--------|------|
| 全自动排产、无人值守 APS | 智能排产方案，生管确认后执行 |
| AI 自动改单、自动下单采购 | 给出建议清单，人确认后执行 |
| 替代用友/金蝶财务总账 | 生产执行系统，财务可对接 |
| 百分百预测交期 / 不良 | 风险等级与预警建议 |
| 通用 ChatGPT 式闲聊助手 | 面向齐套、进度、交期、产量的生产参谋 |
| 减少 XX% 工时（无基线） | 相对贵厂上线前基线对比验收 |
| 外挂 AI 改造任意旧 ERP | 我们是生产执行 ERP，Agent 原生内嵌 |
| AI 自动排版 / 全线视觉质检已标配 | 规则损耗与追溯先落地；视觉属后期可选 |
