## 0. 读数纪律

| 字段 | 可靠程度 | 说明 |
|------|----------|------|
| 客户数 | **低–中** | 官网营销自称；可能含历史户、多产品线加总、未去重 |
| 公司规模 | **中** | 仅云管家等少数披露「员工 100+」；其余多未披露编制 |
| 定价 | **低** | 无公开价目表；下表为产区常见成交带 + 厂商计费话术 |
| 收入 | **极低** | 无私企财报；仅允许内部量级沙盘，**禁止当对外事实** |
| 私有化 | **中–高** | 看产品叙事与产区惯例；具体以合同为准 |
| 口碑 | **中** | 综合官网案例密度、产区传言、产品站可信度；无系统化第三方评分 |

## 2. 分厂商要点

### 2.1 小牛（niuerp.cn）

| 维 | 公开信息 | 解读 |
|----|----------|------|
| 规模 | 「15 年」「三产品」；无员工数/营收 | 产区垂直小–中型软件公司画像 |
| 客户 | 官网 1000+；鞋业 800+ 等 | 上沿；旺铺旧文曾出现更小数字，活跃户宜打折 |
| 定价 | FAQ：**年费制**，升级/维护含年费；轻量版给 ~100 人厂 | 与「买断一次」老模式不同，偏订阅 |
| 私有化 | 推手机/云看板；产区成交仍常要本地 | 售前按「可本地」准备 |
| 口碑 | 外协、鞋底排模、扫码全流程证言多 | 强在「像整条鞋产业链」；决策面弱 |

### 2.2 云管家（ygjsoft.com）

| 维 | 公开信息 | 解读 |
|----|----------|------|
| 规模 | **员工 100+**；温州/泉州/台州等；高新等资质话术 | 组织信息相对最具体 |
| 客户 | **500+** 鞋业生产企业 | 温州女鞋/童鞋/安全鞋案例清单长 |
| 定价 | 产品线 Y1 小微 / Y3 中小 / Y6 中型 + MES | 无挂牌价；分档利于报价 |
| 私有化 | 传统 ERP + 云服务并存 | 中型厂本地部署仍主流 |
| 口碑 | 「简单易用」、箱唛验箱、财务一体 | 区域粘性高；跨省品牌弱于「鞋底专版」叙事 |

### 2.3 泛普鞋业（fanpusoft）

| 维 | 公开信息 | 解读 |
|----|----------|------|
| 规模 | 多行业站点，鞋页与工程/装饰内容混排 | **不是**专注成鞋的产区厂商 |
| 客户 | 无可信鞋业客户总量 | 勿用其「知名」当鞋厂背书 |
| 定价 | 「数千至数十万」 | 几乎无锚点 |
| 私有化 | 明确双模 | 话术完整 |
| 口碑 | 外发/核准算料等**清单完整** | 适合当顾问验收对照；不适合当标杆客户 |

### 2.4 华软（huasoftware.com）

| 维 | 公开信息 | 解读 |
|----|----------|------|
| 规模 | 温州小团队 | 长尾本土 |
| 客户 | 名典、巨日等名录型案例 | 无规模数字 |
| 定价 | 不透明 | APS 可卖「加在现有 ERP 上」 |
| 私有化 | 本地；公开材料技术栈偏旧 | 强调刀模约束排单 |
| 口碑 | APS/合刀垂直味道 | 移动化与产品体验压力大 |

### 2.5 澜东\*（doersoft / dongerp）

服装/品牌 SCM + 工厂 ERP + Agent 中台；**600+**、上市客户背书强。客单与项目制高于产区鞋 ERP。只借「快反/插单/智能体」叙事，**不要**放进成鞋四强报价对照。

## 4. 私有化：产区结论

1. 中小成鞋 OEM / 外贸代工：**多数合同要私有化或专有云**（客户资料、配方、单价敏感）。  
2. 小牛、云管家、华软：**必须能私有化**才像可选供应商；「仅公有 SaaS」在产区难打穿。  
3. 云/年费：小牛强调年费；与私有化不矛盾（本地部署 + 年维保/订阅）。  
4. **对我方：** 售前材料写清私有化/专有云路径与边界（备份、升级、谁运维）。

## 5. 定价对照（内部销售用）

| 档 | 常见首年总包（含实施，中小成鞋） | 谁在抢 |
|----|----------------------------------|--------|
| 入门 | ~5–10 万 | 小微厂、Y1/轻量版叙事 |
| 主流 | ~10–30 万 | 云管家 Y3/Y6、小牛标准 |
| 偏高 | 30 万+ | MES/APS/多厂；撞华软 APS、大厂数字化 |

持续年费通常 **低于首年**。我方宜用「决策面 + 齐套 + 排产确认 + 计件」拉高感知价值，用外发等验货项避免被砍到纯入门价还交不出单据。
