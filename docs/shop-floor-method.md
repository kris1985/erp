> **状态：** 方法定稿（供评审，未绑定现有实现）

## 0. 一句话方法

**鞋上只有一个码（一捆一码）；排产定「哪天、哪些人」；派工定「谁能做多少」；报工扫「鞋上的码」且受捆量/配额/计划三层上限卡住；质检扫同一码独立记不良、不碰工资；乱报靠「事前防 + 事中拦 + 事后查」三层防线兜住。**

---

## 1. 防乱报工总原则（先立规矩）

报工 = **进度** + **工资**，乱报双输（虚进度坑排产、虚产量坑工资）。所以防乱报工不是「加一个校验」，是三层防线：

```text
事前防（能不能报）    派工名单 / 工位绑工序 / 货上码 / 捆量 / 月结锁定
事中拦（报得对不对）  配额上限 / 计划上限 / 单价锁定 / 单笔数量上限
事后查（报错没报错）  异常核对 / 员工签字 / 质检独立 / 追溯反查 / 进度对账
```

**核心原则（10 条）：**

| # | 原则 | 防什么 |
|---|------|--------|
| P1 | 报工必须有据（派工/扫码/货上码），不许凭空手输单号 | 冒报、报别人的单 |
| P2 | 工位只定工序、不定货 | 报错工序 |
| P3 | 一捆一码，报工扫捆码，数量 ≤ 捆量 | 超捆乱报 |
| P4 | 个人配额封顶（派了多少最多报多少），超要确认 | 超派工虚报 |
| P5 | 工序计划封顶（累计 ≤ 计划量），超要确认 | 超计划虚报 |
| P6 | 报工瞬间锁单价，事后改价不影响已报 | 改价套利 |
| P7 | 月结锁定后禁止报工/改数/作废 | 发完工资再翻账 |
| P8 | 质检独立登记，不良**不自动扣工资** | 质检与工人串通/借质检扣款 |
| P9 | 员工小程序核对本人工资 + 签字确认 | 冒名/漏报/错算，本人最敏感 |
| P10 | 报工累计 vs 实际产出（入库/出货）定期对账 | 系统性虚报 |

## 2. 各工序段作业法

> 每段四块：派工 → 报工 → 质检 → 防乱报重点。

### 2.1 裁断（cut，个人·按刀/按双计件）

| 环节 | 做法 |
|------|------|
| **派工** | 按单派裁断工，给配额（可报上限）；皮料按款领料 |
| **报工** | 开裁时生「一单多码」捆码贴到各捆 → 裁断工**扫捆码**报本刀/本捆双数 |
| **质检** | 裁断自检 + 皮料瑕疵登记（挂捆码，原料问题走 IQC 追溯） |
| **防乱报** | 捆码绑定（P3）+ 配额（P4）；领料量与报工量可对（P10） |

### 2.2 针车（stitch，个人计件）

| 环节 | 做法 |
|------|------|
| **派工** | 按单/按捆派针车工（细派），给配额；未派完进「未分配池」 |
| **报工** | **扫筐码**个人报工（一筐一码，筐码带出批次）；多单可换单 |
| **质检** | 针车巡检（IPQC 抽检）+ 返修登记（挂筐码/责任工序） |
| **防乱报** | 派工名单（P1）+ 筐码（P3）+ 配额（P4）+ 返修不重复计件（政策禁区：集体返修禁止） |

### 2.3 成型（forming，履带·集体计件）

| 环节 | 做法 |
|------|------|
| **派工** | 按「线」整工序粗派（排产定日子 + 粗派人），**不做个人细派** |
| **报工** | **线产量报工**：组长/统计员在流水线尾报「这条线合格/不良/返修」；系统按技能系数拆给**勾选的出勤成员**（请假勾掉，不参与拆分） |
| **质检** | 成型巡检（IPQC）+ 下线终检（FQC）；不良挂批次（**筐码到成型就断，追溯看批次不看筐**） |
| **防乱报** | 出勤勾选（请假剔除）+ 线产量 vs 下线数对账（P10）+ 不良独立登记不扣工资（P8） |

> 关键：成型是**线级产量**，不是个人产量。个人扫工位报工不符合履带实况，虚报/对不上线尾数是必然。

### 2.4 包装（packing，个人计件 + 末道装箱）

| 环节 | 做法 |
|------|------|
| **派工** | 按单派包装工（个人配额）；装箱末道单独设「装箱」岗 |
| **报工** | ① 普通包装工：扫工位码/单号报双数 ② 装箱末道：**装一箱扫箱唛 = 报一箱**（按箱内双数记计件，轻量，不做逐双验箱） |
| **质检** | FQC 终检 + 出货验箱（QC/仓管逐双核对色码，与计件分开） |
| **防乱报** | 扫箱唛绑定（P3 变体：报工量=箱内双数，不可超）+ 配额（P4）+ 出货验箱兜底（P10） |

> 关键：**扫箱唛报工 ≠ 扫箱唛验箱**。前者给工人（轻量记双数），后者给 QC/仓管（逐双核对），不能混。

### 2.5 铲皮（skiving，可选段·个人计件）

| 环节 | 做法 |
|------|------|
| **派工/报工** | 同裁断：按单派 + 扫捆码个人报 |
| **质检** | 铲皮破损/厚度不良登记 |
| **防乱报** | 同裁断 |

## 3. 派工（统一规则）

| 层次 | 谁做 | 粒度 | 作用 |
|------|------|------|------|
| **排产（粗派）** | PMC | 日子 + **整工序** | 定「哪天、哪个工序、大概几人」 |
| **派工（中派）** | 主管/组长 | 单 × 工序 × 工人 + **配额** | 定「谁做、最多做多少」，是防乱报的 P1/P4 前提 |
| **按捆细派（细派）** | 组长（可选） | 捆 × 工人 | 有货上码之后的加强，非必需 |

**请假处理：** 请假 → 「收回剩余配额」锁到已报量，剩余回未分配池改派；成型线则靠报工时勾掉请假者（上一版已落地）。

## 4. 报工（统一规则 + 分段差异）

**统一载体：** 鞋上只有一个码（一捆一码 `TraceUnit`），报工/不良/追溯都扫它；工位码只定「本工序」、不定货。

| 类型 | 计件？ | 进度？ | 说明 |
|------|--------|--------|------|
| 合格 | ✅ 计件 | ✅ 推进度 | 主路径 |
| 不良 | ❌ 不计件（独立登记） | ⚠️ 记缺陷 | 不自动扣工资（P8） |
| 返修 | 按返修价 | 不重复推进度 | 集体工序返修禁止（政策） |
| 补数/尾数 | 按补数/尾数价 | 计入 | 扫码/对话可报 |

**分段报工方式总表：**

| 段 | 类型 | 报工入口 | 追溯维度 |
|----|------|----------|----------|
| 裁断 | 个人 | 扫捆码 | 捆码 + 批次 |
| 针车 | 个人 | 扫筐码 | 筐码 + 批次 |
| 成型 | 集体（线） | 组长线尾报线产量 | **批次**（筐码断） |
| 包装 | 个人 + 装箱 | 扫工位/单号；末道扫箱唛 | 箱唛 + 批次 |
| 铲皮 | 个人 | 扫捆码 | 捆码 |

## 5. 质检（三检 + 在制不良）

| 类型 | 环节 | 对象 | 结果 |
|------|------|------|------|
| **IQC 来料检** | 采购到货 | 物料 | 合格入池 / 让步 / 退货 |
| **IPQC 巡检** | 针车、成型过程 | 半成品抽检 | 不良挂工序/捆，触发返修 |
| **FQC 终检** | 成型下线、包装 | 成品 | 不良拦截，不流入出货 |
| **出货验箱** | 装箱/出货 | 箱内色码 | 错码/超箱拦截 |

**三条铁律：**
1. **质检独立**：不良登记不自动扣工资（P8），质检结论不进工资自动流，只做拦截与追溯。
2. **同码追溯**：不良/返修扫同一货上码，能反查到「哪捆、哪道工序、谁做的」（B2g）。
3. **IQC ≠ 在制不良**：来料问题走 IQC，别混进在制缺陷账。

## 6. 防乱报工机制清单（逐条对照）

| 机制 | 防什么 | 竞品做法 | 建议 |
|------|--------|----------|------|
| 派工名单校验 | 冒报/报别人的单 | 垂直普遍「先派工再报」 | 硬校验（可租户开关） |
| 工位绑工序 | 报错工序 | 小牛「工序扫码」 | 工位只定工序 |
| 货上码/一捆一码 | 凭空报、跨捆报 | 竞品「流程卡/捆扎卡一码」 | 主路径 |
| 捆量上限 | 超捆乱报 | 竞品按卡数量 | 报工数 ≤ 捆量 |
| 个人配额封顶 | 超派工虚报 | 垂直「派工配额」 | 超配额确认 |
| 工序计划封顶 | 超计划虚报 | 垂直「计划 vs 实绩」 | 超计划确认 |
| 单笔数量上限 | 多打 0 | 竞品少见显式 | 单笔 ≤ 计划量拦截 |
| 报工锁价 | 改价套利 | 垂直「报工锁价」 | 报工瞬间快照单价 |
| 月结锁定 | 发完再翻账 | 垂直「月结」 | 锁定后禁改 |
| 异常核对（A2f） | 系统性异常 | 垂直靠人工对表 | 规则高亮可解释 |
| 员工签字确认 | 冒名/漏报/错算 | **云管家：小程序核对工资签字** | 本人核对 + 签字（✅ 已落地：月结锁定后本人签，解锁重签，管理端不代签） |
| 质检独立 | 质检/工人串通 | 垂直「不良不自动扣工资」 | 铁律 |
| 追溯反查 | 事后追责 | 泛普 QCS 追溯 | 一码一捆 |
| 进度对账 | 系统性虚报 | 垂直「报工 vs 出货」 | 累计 vs 入库/出货 |

## 7. 竞品对照摘要

| 竞品 | 报工 | 质检 | 防乱报亮点 |
|------|------|------|-----------|
| **小牛** | 裁断→针车→成型→包装全工序扫码，实时看板 | IQC/IPQC/FQC 全流程 | 扫码 + 看板实时（进度虚报难藏） |
| **云管家** | 扫码报工自动生成工资；委外扫码出库入库 | 品质/薪资/设备 | **员工小程序核对工资 + 签字** |
| **泛普** | 条码/RFID 报工 | QCS 质量追溯 | 追溯反查 |

**竞品共性：** ① 扫码是唯一报工入口 ② 报工即工资、进度同源 ③ 员工自核对是兜底。**竞品普遍缺：** 可解释的异常核对（A2f）、线产量出勤勾选（成型请假）、扫箱唛报工与验箱分离——这三点恰是我们可打的差异化。
