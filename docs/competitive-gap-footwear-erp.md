# 竞品对照：用友 / 金蝶 / 鞋业垂直 ERP × 本系统

> 鞋业专用 ERP 产品视角。对比对象：  
> - **通用 ERP**：用友 U8/YonSuite、金蝶云星空/K/3 等制造+财务套件  
> - **鞋业垂直**：泛普、小牛、云管家、澜东类「鞋帽包箱」方案等  
> 不是功能清单打分，而是：**鞋厂买账的能力你们缺什么、通用 ERP 强在哪、垂直 ERP 强在哪、你们反而超前在哪。**  
>  
> **▶ 已据此标定的产品优先级总源 → [`product-roadmap.md`](./product-roadmap.md)**  
> **▶ 合批 × 智能排产专项竞品 → [`design/competitive-merge-schedule.md`](./design/competitive-merge-schedule.md)**

## 1. 一句话定位差

| 类型 | 典型卖点 | 鞋厂真实感受 |
|------|----------|--------------|
| 用友 / 金蝶 | 财务合规、总账应收应付、库存多组织、标准 MRP/生产订单 | 「能记账、能进销存」；**色码/楦/外发/配码装箱要二次开发或凑合** |
| 鞋业垂直 ERP | 分色分码、配码装箱、外发对账、刀模楦头、流程卡/箱唛 | 「鞋厂流程熟」；常弱在**轻量排产决策、接单经营判断、移动报工体验、AI 参谋** |
| **本系统** | 计件报工+齐套池分配+规则排产/插单+接单决策面+军师辅路径 | **车间执行与接单拍板偏强**；鞋业「单据闭环」与财务深度偏弱 |

## 2. 对照总表（缺什么 / 不够好 / 可借鉴）

| 能力域 | 用友/金蝶 | 鞋业垂直 | 本系统 | 差距判断 | 可借鉴 |
|--------|-----------|----------|--------|----------|--------|
| **财务总账 / 税务 / 多组织** | 极强 | 中（常对接或简化） | 弱：应收/回款/利润有，无完整总账税务 | ❌ 不是鞋厂第一刀，但上规模会卡 | 用友金蝶：凭证、期间、往来核销成熟度；可「业务系统 + 财务对接」而非自研全套 |
| **标准进销存 / 多仓货位** | 强 | 中–强 | ⚠️ 池+分配模型先进叙事，货位/盘点浅 | 🚫 完整 WMS 已明确不做 | 垂直：批次/色差库存、鞋底按码入库 |
| **分色分码主数据** | 弱（靠自定义） | **极强**（矩阵展开） | ⚠️ 订单色码有；主数据/对照弱 | ❌ **楦头/肥度/刀模/大底模具**几乎空白 | 垂直：楦号、SIZE RUN、楦间对照 |
| **色码级 / 分段 BOM 算料** | 弱 | **极强**（按码、复合工艺算料） | ❌ 总需求×单耗；色码 BOM 未做 | ❌ **相对垂直最大硬伤之一** | 泛普等：BOM 核准数→精确需求；换料版本 |
| **样品 / 打样 → 大货** | 弱–中 | **强**（样品 BOM 与订单共享、研产一体） | ❌ 无打样/产前资料移交闭环 | ❌ 外贸/品牌鞋厂痛 | 澜东类：资料移交、产前准备任务链 |
| **订单变更版本** | 中（反审麻烦） | **强**（一键变更留版本、下游可跟） | ⚠️ 改量重算料有；❌ 版本号/变更单弱 | ⚠️ 改码补数向导也缺 | 垂直：变更不靠整单反审 |
| **外发 / 外协加工** | 有委外模块（偏标准） | **极强**（发料收回、损耗、对账） | ❌ 无外发工序单 | ❌ 针车/硫化厂刚需 | 小牛/泛普：外发全程+损耗率 |
| **配码装箱 / 箱唛 / 内盒标** | 弱 | **极强** | ❌ 出货色码行级 | ❌ 出口/商超单刚需 | 云管家：一键内盒外箱标；扫码校验装箱 |
| **齐码出货 / 成品仓** | 中 | 强 | ⚠️ 完工/出货账有，未卡齐码 | ⚠️ 半截 | 垂直：可出码、扫码出货 |
| **齐套 / 争料** | 标准齐套 | 齐套进度+到料分配 | ✅ 池承诺互斥 + 接单争料 | ✅ **相对通用 ERP 的差异化** | 可把「争料保谁」做成采购动作，不只展示 |
| **生产计划 / APS** | 有限产排程（重、贵） | 中（指令单/生管计划） | ✅ 规则倒排/正排/插单冲击+HITL | ✅ **轻量排产决策优于多数垂直「只出指令单」** | 别学大 APS；学垂直的「指令单一页纸」 |
| **现场条码 / 流程卡 / PDA** | 加模块 | **强** | ⚠️ 捆标/过站/扫码报工有；❌ 开裁流转卡/箱唛弱 | ⚠️ 执行链有，单据打印链弱 | 垂直：指令单/流程卡/外箱贴一体 |
| **计件工资** | 弱或外挂 | 中 | ✅ 报工锁价、月结较完整 | ✅ **相对金蝶用友鞋厂现场的优势** | 人事奖惩请假仍缺（已定稿） |
| **接单经营判断**（毛利/冲击/回款） | 弱（另买分析） | 弱–中 | ✅ 生产分析决策面 + 假设仿真 | ✅ **明显超前垂直与通用** | 保持；批价入口补齐 |
| **AI / 军师** | 近年有助手，偏总账问数 | 少 | ✅ 工具白名单军师 + 左栏不堵 AI | ✅ 定位正确则是卖点 | 用友金蝶：问数接财务；你们接车间决策 |
| **客供料** | 中 | 中 | ⚠️ 规则有、收货台无 | ⚠️ | 垂直少讲透，可做成差异化 |
| **IQC 来料检** | 有 QM 模块 | 中 | ❌ | ⚠️ 面料色差场景 | 金蝶/用友质检流程可简化抄 |
| **多品牌 / 订货会 / 渠道** | 分销强 | 品牌鞋强 | ❌ 偏 OEM 生产 | 🚫 除非转品牌零售 | 澜东：订货会/快反——非 OEM 主战场可暂缓 |
| **鞋底 / 鞋材专版** | 无 | 小牛等有造粒/排模 | ❌ | 🚫 除非客户是底厂 | 认清边界：成鞋组装 OEM |

## 3. 你们「缺」的分层（别平均用力）

### 3.1 相对鞋业垂直：硬缺口（会被实施顾问一眼看穿）

| 缺口 | 为何致命 | 建议 |
|------|----------|------|
| 色码/分段 BOM 与精确算料 | 采购与齐套根基错，后面分析都像装修 | 单独立项，对标垂直算料，不塞进军师 |
| 外发加工闭环 | 长三角/泉州大量外发面/底 | 外发单：发–收–损耗–加工费 |
| 配码装箱 + 箱唛/内盒 | 外贸验货、商超验箱 | 出货域补齐，不必上完整 WMS |
| 楦/刀模/大底等鞋业主数据 | 打样与大货沟通语言 | 先主数据轻量，再绑 BOM |
| 样品→大货 / 变更版本 | 改单不断，无版本就扯皮 | 变更单+历史版本，学垂直「不整单反审」 |
| 开裁/流程卡打印体验 | 现场仍认纸 | 快赢，复用已有色码工序 |

### 3.2 相对用友/金蝶：弱但可「借力」

| 缺口 | 策略 |
|------|------|
| 总账、固定资产、税务、合并报表 | **不要做成用友**；做好业务单据与凭证接口/导出 |
| 多组织、集团供应链 | 中小 OEM 后置；单工厂先打穿 |
| 标准成本核算引擎 | 你们有利润/成本卡/实耗；深化「款成本」即可，不必完整成本会计 |
| 正式 QM 质检模块 | 先 IQC 挂到货 + 不良返修闭环，够用 |

### 3.3 你们已有、竞品常弱（护城河，要讲清楚）

| 优点 | 怎么讲给鞋厂 |
|------|----------------|
| 接单决策面（冲击/争料/色码/回款） | 「接单不靠拍脑袋，也不等大 ERP 出报表」 |
| 规则排产 + 插单冲击 + 人工确认 | 「比 Excel 强，比百万 APS 便宜可控」 |
| 计件报工–工资闭环 | 「现场扫了就能算钱」 |
| 池库存分配互斥齐套 | 「不会两单同时假装齐套」 |
| 军师辅路径（不堵主路径） | 「AI 解释，确认仍在人」 |

**风险：** 若外发/装箱/色码 BOM 长期空缺，客户会说「不像鞋厂系统」——护城河会被「缺件」盖过。

## 4. 做得不够好 / 没考虑到的（产品债，不只是没做）

| 问题 | 表现 | 竞品对照 |
|------|------|----------|
| **鞋业对象模型偏「服装通用制造」** | 有色码行，但缺楦、刀模、SIZE RUN、配码规则一等公民 | 垂直开箱即有 |
| **单据体验弱于台账能力** | 过站/报工有了，流程卡/箱唛/外发单纸面闭环弱 | 垂直靠「一页指令单」赢现场 |
| **变更与版本意识不足** | 改量会重算，但缺少「变更单、谁批的、旧版还给供应商吗」 | 澜东等强调一键变更留版 |
| **出口/商超包装未进主路径** | 出货停在色码数量 | 垂直装箱是标配 |
| **财务叙事不清晰** | 有利润回款，客户仍问「能不能替金蝶」 | 应明确：**生产执行 ERP，财务可对接** |
| **分析能力超前于主数据深度** | 色码曲线、争料很亮，算料仍按总双 | 垂直先算准料，再谈分析——你们要补齐否则「聪明但不准」 |
| **多工厂/外发产能未建模** | 排产偏本厂工序 | 垂直外发=产能延伸 |

## 5. 建议产品叙事（对客户怎么说）

```text
我们不是小型用友/金蝶：
  → 不拼总账税务，拼「接单拍板 + 齐套不打架 + 计件工资 + 可确认的排产」。

我们要对标鞋业垂直的「像鞋厂」：
  → 下一阶段补：色码算料、外发、装箱箱唛、流程卡、变更版本。

我们比多数垂直多出来的：
  → 接单经营决策面、插单冲击、军师解释（主路径不依赖 AI）。
```
