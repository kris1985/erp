# Agent 能力 OKR：已有 / 补齐 / 不做

> **范围：** Agent / 军师 / 决策辅助（含从外部方案提炼的增强项）。  
> **原则：** 大模型只理解与解释；数量/交期/金额走规则；落库 HITL；**嵌本系统，不做外挂业务中台**。  
> **总纲：** [`product-roadmap.md`](./product-roadmap.md) §4.3  
> **宣传：** [`marketing-pain-agent-brochure.md`](./marketing-pain-agent-brochure.md)

## 0. 本期北极星（Agent）

### O1 · 齐套与交期参谋可执行
| KR | Agent | 退出 |
|----|-------|------|
| KR1 | 齐套检查 | 三入口齐套日一致；催料可跳转 |
| KR2 | 进度追踪 | 风险条+原因；今日 3 件事含进度/交期 |

### O2 · 问数与排产是参谋不是自动驾驶
| KR | Agent | 退出 |
|----|-------|------|
| KR1 | 自然语言问数 | 白名单覆盖产量/进度/缺料/交期；关 AI 同结论可点到 |
| KR2 | 智能排产 | 插单冲击可演示；A/B 对比卡可讲清 |

### O3 · 报价与品质有依据
| KR | Agent | 退出 |
|----|-------|------|
| KR1 | 报价辅助 | 同类实绩有/无空态通过 |
| KR2 | 品质预警 | 抽检建议进今日行动或质量入口 |

> **下波 Agent 增强（不挤 B2a）：** A2d IM/日报 → A2e 损耗对比 → A2f 异常核对；B2a+ 等外发单。

## 1. 核心 Agent（主宣传 · 已有为主）

| Agent | 对外一句话 | 已有 | 补齐 | 不做 |
|-------|------------|------|------|------|
| **齐套检查** | BOM×库存×在途→缺料/建议采购/齐套日 | 池互斥、缺料、在途、ETA、争料、intake | 催料闭环、A2d 推送 | AI 自动下 PO；ML 替齐套账本 |
| **进度追踪** | 报工算进度；落后预警；可推日报 | 报工、风险条、今日 3 件事、捆过站 | 归因话术；**A2d** IM+日报 | 编进度；替代班组管理 |
| **自然语言问数** | 说话只查不改 | 军师白名单；接单问军师 | 厂级固定问法；IM 通道 | **NL2SQL 写库**；闲聊 Bot |
| **智能排产** | 方案+插单冲击；人确认 | 正排/倒排、仿真、HITL | A2c 对比卡；与今日「可排」串联 | OR-Tools 主路径；自动落库；蒙特卡洛主 UI |
| **品质预警** | 事前加严、事后可追 | 不良、返修、捆标、不良汇总 | **A2b** 抽检进今日行动 | 无数据硬上模型；全线视觉质检；集体返修 |
| **报价辅助** | 区间+依据；人出价 | 成本卡、实耗偏差、A1c 实绩 | 批价体验；驱动分解 | AI 自动对客发价 |
| **接单决策参谋** | 打开即拍板 | 左栏主路径全套 | 空态引导 | AI 自动确认接单 |

## 2. 增强 Agent（外部方案吸收 · 已入总纲）

| Agent | 总纲 ID | 已有 | 补齐 | 不做 |
|-------|---------|------|------|------|
| **IM 预警 + 进度日报** | A2d | 系统内今日行动/风险 | 企微/钉钉推送；日报可点回；只推不改 | 推送里直接改单 |
| **损耗对比**（皮料/关键料） | A2e | BOM、领料、报工、按码算料 | 材质标准损耗率；实耗对比；超标→今日行动 | **AI 裁断排版**；视觉硬件入门 |
| **计件/成本异常核对** | A2f | **计件月结引擎已有** | 异常行高亮初稿；可选直接成本异常 | 重做工资引擎；金蝶级费用全量分摊 |
| **外协催收与厂评分** | B2a+ | — | **先 B2a** 发收损耗加工费；再未回/超期/评分 | 无外发单做「智能外协」 |
| **订单 OCR→导入初稿** | A3f | 结构化销售单主路径 | 解析→匹配款→导入草稿；异常高亮；人确认 | OCR 当一期主叙事；AI 直接写正式单 |
| **来料/对账 OCR** | A3g | PO/入池 | 匹配 PO 差异清单；外协对账依赖 B2a | 任意格式 100% 识别承诺 |
| **呆滞/替代/临期** | A3 ABC-XYZ | 争料线索 | 认领后消耗速度/安全库存建议 | 当前主宣传；自动改 BOM |

## 3. 共用禁区（所有 Agent）

| 禁区 | 原因 |
|------|------|
| 大模型直接改订单/库存/工资 | 幻觉改账 |
| NL2SQL 无白名单写库 | 串数、不可审计 |
| LLM 算齐套/排产/报价金额 | 不可审计 |
| 外挂第二套业务中台 | 两套账、员工双系统 |
| 私有化大模型必选 | 中小厂性价比低 |
| AI 裁断排版 / 全线视觉质检作入门 | 硬件重、噱头 |
| 无厂测基线的「降 80% 工时」验收 | 销售稿当 KPI |
| 全自动落库排产/采购/放货 | 必须 HITL |

**允许：** 意图识别、解释指标、预警推送、OCR/表格出草稿、组装白名单工具结果。
