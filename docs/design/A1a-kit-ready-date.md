> **状态：** 已验收（2026-08-09）  
> **总纲：** [`product-roadmap.md`](../product-roadmap.md) §7 A1a  
> **依赖：** B1c 按码缺料/采购已接上（在途 ETA 按码匹配）

---

## 1. 字段与口径

| 字段 | 含义 |
|------|------|
| **预计到料日** `expected_ready_date` | 某一缺料行预计可供日 |
| **预计齐套日** `kit_ready_date` / `earliest_start` | 本单（或当前缺料集合）各缺料行预计到料日的**最晚一天** |

已齐套 / 无缺料 → 日期为空，UI 统一显示 **「—」**（不做「已齐」文案，避免与日期列混淆）。

接单侧 `analytics.order_intake.material_eta` 同源函数 [`estimate_material_etas`](../../app/services/purchase_service.py)，文案保持「预计到料日 / 预计齐套日」。

---

## 2. 计算规则（规则 ETA，非 ML）

1. **有在途 PO 行**（未收完）：`PO.expected_date`（缺省则下单日 + 默认采购周期）+ 供应商历史延迟中位 → 预计到料日；来源 `in_transit`  
2. **无匹配在途**：今日 + 物料历史周期（否则供应商周期，否则租户默认 lead）→ 预计到料日  
3. **按码匹配**：在途键 = `(supplier_product_id, size_id)`；未按码 `size_id=None`。42 码在途**不能**覆盖 37 码缺料行  
4. **预计齐套日** = 参与计算的缺料行到料日 `max`

---

## 3. 三入口（须同单一致）

| 入口 | 展示 |
|------|------|
| 缺料汇总 | 行：预计到料日；响应附 `kit_ready_by_order_id` |
| 生产单列表 | 列：预计齐套日（仅缺料单有值） |
| 生产单详情 · 概览 / 用料 | 头：预计齐套日；用料缺料行：预计到料日 |
