# 垂直竞品分析：合批 × 智能排产

> **范围：** 仅「合批/合单生产协同」与「生产计划/排产/APS」两域。  
> **对照对象：** 鞋业垂直（泛普、小牛、云管家、华软/温州本土、澜东类）· 通用制造 APS（安达发等）· 用友/金蝶制造套件。  
> **本系统锚点：** B2f 合批（合批不合单）· `schedule_engine` 规则粗排 + HITL · 军师辅路径。  
> **总纲：** [`competitive-gap-footwear-erp.md`](../competitive-gap-footwear-erp.md) · [`merge-batch-aps-alignment.md`](./merge-batch-aps-alignment.md) · [`aps-dev-review.md`](./aps-dev-review.md)  
> **记录日期：** 2026-08-09。公开宣传 ≠ 客户现场深度；结论按「中小成鞋 OEM 买账点」归纳。

---

## 1. 一句话格局

| 阵营 | 合批/合单 | 排产 | 中小厂真实感受 |
|------|-----------|------|----------------|
| **鞋业垂直 ERP** | 常有「订单合并生产 / 指令单合刀」叙事；楦模、流程卡强；账本多为指令/生产单体系，合单深度厂商差极大 | 多数是**生管排单 + 齐套检查 + 指令下发**；头部宣传甘特/分线；少见可解释插单冲击 | 「像鞋厂、能出纸」；计划仍大量靠 Excel/老师傅 |
| **通用 ERP + 外挂 APS** | 合批非鞋业一等公民；要二次开发色码/楦 | 有限产 APS 强但重、贵、实施长 | 中小鞋厂难落地 |
| **独立 APS 厂商** | 换模/合批作约束优化目标 | 机台小时、模具、甘特是主业 | 要先有干净主数据；与鞋业单据常两张皮 |
| **本系统** | **合批 L1+L2 已上**（组批+卡，账本分单）；推荐引擎待补；真合单闸门后 | **轻量规则排产 + 插单仿真 + HITL + 军师**已上；非甘特 APS | 「比 Excel 强、比 APS 便宜可控」；缺垂直单据时会被说不像鞋厂 |

**定位结论：** 在「可确认的粗排 + 插单」上相对多数垂直有差异化；在「合刀纸面/指令一体、楦模合单、外发进排产」上仍落后头部垂直。竞品战场应是 **计划决策质量**，不是去拼安达发级 APS。

## 2. 合批 / 合单：竞品怎么做

### 2.1 能力光谱（行业常见四档）

| 档 | 含义 | 典型谁强 | 本系统 |
|----|------|----------|--------|
| **L-纸** | 合刀纸面、汇总色码、流转卡 | 垂直标配（指令单/开裁卡） | ✅ B2f 合批卡 |
| **L-组** | 多订单/多生产单组成批，仍分单领料报工 | 部分垂直「合并生产」实为组批 | ✅ B2f；缺自动推荐 |
| **L-料** | 同皮料跨款合版算料、合并采购需求 | 垂直 + 算料强者；常绑 CAM 话术 | ⚠️ 可按料加总采购建议；❌ 无跨款同料聚类、无 Nesting |
| **L-账** | 母指令/真合单 + 分配 + 合并领料成本摊 | 深实施垂直 / 定制；非家家有 | ❌ 闸门后 B3c；刻意不做无分配硬合并 |

### 2.2 分厂商印象（宣传口径归纳）

| 厂商/类型 | 合批相关公开能力 | 对中小厂含义 | 对我们的启示 |
|-----------|------------------|--------------|--------------|
| **云管家类** | 明确提「支持订单合并生产」、指令条码、排单进度 | 合并生产是**卖点菜单项**；现场仍靠指令单扫码 | 合并要能讲；但交付常是指令层，未必真合单账本 |
| **小牛（鞋业）** | 齐套、分线、甘特排产；外协强；鞋底线另有排模 | 成鞋侧重排单管控；底厂才深模具 | 成鞋 OEM 对标「齐套+排单」即可；勿拿鞋底排模吓自己 |
| **泛普类** | 计划/追踪/外发/采购欠数全；少主打「智能合批引擎」 | 强在流程覆盖与算料采购链 | 合批不是他们唯一杀手锏；单据完整度才是 |
| **华软等温州本土 + APS** | 刀模配套排单、混色混码、配码 BOM；APS 话术重 | 有「按刀模自动排单」垂直味道 | **楦/刀模主数据**是合批/排单可信前提——对齐 B3a |
| **通用 APS** | 少换模/少换料作优化目标 | 中小鞋厂买不起或不愿养 | 印证：合批约束可进规则推荐，不必上优化求解器 |

### 2.3 本系统合批：领先 / 落后 / 该抄什么

| | 内容 |
|--|------|
| **已不弱** | 架构清醒：合批不合单、出货不分批、HITL——比「宣传合并、账本一锅粥」的实施现场更干净 |
| **明显落后** | ① 无**自动合批推荐**（竞品最少有合并生产入口+人工合）② 无楦/底模维度 ③ 合批卡与「指令单+条码一体系」的现场密度仍不如成熟垂直 ④ 跨款同料合刀未做 |
| **不该抄** | CAM Nesting、无分配硬合并、默认报工按批自动分摊 |
| **该抄（产品）** | 合并生产作一等入口；交期窗/客户禁合；刀模楦号进推荐；指令/卡与报工条码同一叙事 |
| **该抄（分期）** | 先 L-纸+L-组+推荐引擎 → 再楦模提示 → 真合单认领 |

## 3. 智能排产：竞品怎么做

### 3.1 能力光谱

| 档 | 含义 | 谁常见 | 本系统 |
|----|------|--------|--------|
| **P0 Excel** | 交期+经验 | 大量中小厂实态 | 要替代的对象 |
| **P1 齐套+排单表** | 欠料可见、已排/未排数量、车间进度 | 云管家/泛普等垂直主流 | ✅ 齐套池+进度；排单表形态不同 |
| **P2 规则/粗产能计划** | 倒排/正排、负荷、插单要人确认 | **本系统主战场**；垂直里参差 | ✅ 三策略+插单仿真+草稿确认+方案对比 |
| **P3 产线甘特 / 分线** | 成型线分配、可视化拖拽 | 小牛等宣传「甘特图排产」 | ❌ 明确不做近端 |
| **P4 有限产 APS** | 机台小时、模具独占、自动重排 | 华软 APS / 安达发 / 金蝶用友高阶 | ❌ P∞ |

### 3.2 分厂商印象

| 厂商/类型 | 排产相关 | 相对本系统 |
|-----------|----------|------------|
| **垂直主流** | 生产计划、齐套、指令下发、进度扫描；「智能」多为规则+人工 | 我们在**插单冲击可解释、多方案 HITL、军师**上更亮；他们在**指令单闭环、外发进计划**上更亮 |
| **小牛** | 物料齐套 + 智能分线 + 甘特 | 甘特/分线是体验压力；我们用工序日产能近似瓶颈，要讲清「够用」 |
| **华软 APS** | 刀模约束、混色混码、配码 BOM 进排程 | 垂直 APS 样板；依赖主数据，实施重——可作「远期/认领」参照，非一期对标 |
| **用友/金蝶** | MRP + 可选 APS | 鞋业色码/合批弱；总账强——不拼排产深度拼财务 |
| **独立 APS** | 换产换模优化、锁定计划、MES 闭环 | 与鞋业 ERP 常集成痛苦；中小厂总拥有成本高 |

### 3.3 本系统排产：领先 / 落后 / 该抄什么

| | 内容 |
|--|------|
| **领先点** | 确定性规则引擎可审计；插单仿真；A/B 方案对比；齐套争料与排产同账本；军师只调工具不改账；接单面与排产联动叙事 |
| **落后点** | 无成型线/甘特；外协未进产能；齐套日喂入开工仍需收口；合批未进池筛；租户加班日/厂休日历浅（仅国定假） |
| **不该抄** | 黑盒全自动最优排程、5 分钟无人全表落库、为对标小牛强上甘特 |
| **该抄** | 垂直的「已排/未排/欠料」一页纸进度感；指令下发与报工同号；刀模/楦进约束（有主数据后）；外发周期当产能延伸（B2a 后） |

## 4. 合批 × 排产：竞品是否「放一起」

| 做法 | 谁倾向 | 评价 | 我们策略 |
|------|--------|------|----------|
| 合并生产在生产模块，排单在计划模块，弱联动 | 多数垂直 | 实施简单，PMC 仍两头跑 | 可接受过渡 |
| 排单时勾选合并 / 合并后生成指令再扫码 | 云管家类叙事 | **中小厂最顺** | **目标体验**：计划中心内「荐批 → 组批 → 出方案」 |
| APS 内把合批/换模当优化目标 | APS 厂商、华软 | 强但重 | 我们用**规则推荐合批**，不进求解器 |
| 合批只是打印、与排产无关 | 部分浅实施 | 纸面有了计划仍 Excel | 正是我们要避免的：B2f 后补池筛+推荐 |

**竞品启示：** 客户感知上「合并生产」和「排单」是同一周 PMC 的事；产品应同屏或同参数（交期窗、工作日历），算法仍可两引擎。

## 6. 对中小鞋厂：谁的组合更「合适」

| 工厂诉求 | 更匹配的竞品姿态 | 我们应呈现 |
|----------|------------------|------------|
| 少换料合刀、少改 Excel | 垂直合并生产 + 简单排单 | **合批推荐 + 粗排确认**（同一计划中心） |
| 要甘特、机台到小时 | 小牛宣传档 / APS | **诚实降级**：工序日产能+负荷，不承诺甘特 |
| 外发一半产能 | 小牛/泛普外协 | 先 B2a，再谈排产完整度 |
| 要一套顶金蝶+排产 | 用友金蝶 | 不拼；拼执行与计划决策 |
| 怕 AI 乱改单 | 多数竞品也不敢真自动 | **HITL 双引擎**（合批荐、排产方案）可正面打 |

**产品判断：** 中小成鞋 OEM 最买账的是「**齐套清楚 + 能合并着干 + 计划能确认 + 急单能看见撞谁**」，不是「APS 最优」。这与垂直主流能力重叠在齐套/指令，与我们差异化重叠在插单/方案/军师——**合批自动推荐是补齐与垂直的「合并生产」对话资格，同时喂给排产池。**

## 7. 竞争策略建议（可执行）

1. **对外话术：** 「合批推荐 + 可确认排产」打包成计划中心；对比垂直说清：我们不强上甘特，强在插单冲击与齐套不打架。  
2. **近端补齐：** 合批规则引擎（交期窗等）+ 排产池按批筛 + 齐套日硬约束；对标云管家「合并生产」入口完整度。  
3. **中期像鞋厂：** B3a 楦底模进推荐提示；B2a 外协周期进倒排——否则排产/合批再聪明也输顾问验货。  
4. **坚决不跟：** 独立 APS 深度、Nesting、无闸门真合单、无人自动落库。  
5. **举证：** 用「出方案到确认时长 / 插单可解释 / 合批采纳率」打赢「有没有甘特」的口水战。

## 8. 结论

| 问题 | 结论 |
|------|------|
| 垂直合批强在哪？ | 纸面指令、合并生产入口、楦模语境；深合单看实施 |
| 垂直排产强在哪？ | 齐套+排单进度+指令扫码；甘特/APS 是头部加分项 |
| 我们强在哪？ | 规则粗排 HITL、插单仿真、齐套池、军师；合批账本干净 |
| 我们该补哪？ | **合批自动推荐**、批进排产、日历加班开关、楦/外协进约束 |
| 合批与排产竞品是否一体？ | 客户侧一体；我们应同参数同入口、双引擎 HITL |

**一句话：** 在鞋业垂直赛道，用「轻量合批推荐 + 可确认智能粗排」打中小 OEM，用单据（外发/楦/箱唛）防止「不像鞋厂」；不要用精 APS 去和安达发或小牛甘特对轰。

## 9. 竞品「智能排产」参数选项清单

> 归纳自：鞋业垂直（华软 APS、小牛、云管家/泛普类宣传）+ 通用/轻量 APS（分派规则、日历、缓冲等公开配置）。  
> **注意：** 宣传参数 ≠ 每家现场全开；中小厂真正调的往往只有少数旋钮。

### 9.1 按参数族分类（竞品常见选项）

#### A. 优化目标 / 排程策略（几乎家家有）

| 参数选项 | 常见取值 | 鞋业语境 |
|----------|----------|----------|
| 主目标 | 交期优先 / 产能（负荷）均衡 / 效率（少换产）/ 成本 / 多目标加权 | 赶交货 vs 少换模换料 |
| 分派方向 | **正排**（从今天往后）/ **倒排**（从交期往前） | 对应我们 `capacity_first` / `delivery_first` |
| 能力模式 | 有限产能 / 无限产能（只排顺序不算撞车） | 粗排常先无限再看负荷 |
| 规则优先级 | EDD 最早交期、SPT 最短工时、危急比 CR、订单优先级数、客户等级 | 急单/VIP 插队 |
| 多方案 | 同时出 N 套（保交期/保效率/保大客）再选 | 我们已有三策略 + A/B 对比卡 |

#### B. 工作日历与时间（APS 标配，垂直深浅不一）

| 参数选项 | 常见取值 | 说明 |
|----------|----------|------|
| 标准工作日 | 周一～周五 / 大小周 | 基础日历 |
| 班次 | 一班/两班；每班起止时刻；开动率 % | 精细 APS 到小时；粗排常折成「日产能」 |
| 法定假 / 调休 | 国定假日历 | 我们已有 `cn_holidays` |
| 例外停工 | 维保、停电、年休、自定义厂休 | 租户级例外日 |
| 加班窗口 | 可排周六日/晚班；加班上限小时 | 「非工作日是否排产」开关 |
| 排产滚动起点 | 从哪天开始算首单 | 计划组开始时间 |
| 缓冲 | 工序间缓冲 % 或小时；产能缓冲 10%～15% | 防插单/故障把计划撑爆 |

#### C. 产能与资源（垂直鞋业 vs 通用 APS）

| 参数选项 | 鞋业垂直常见 | 通用 APS 常见 |
|----------|--------------|---------------|
| 日/班产能 | 裁断组、针车组、成型线 **双/天**（按鞋型分类） | 设备产能曲线、可用率 |
| 资源粒度 | 班组 / 产线 / 组别×产品类别 | 机台、工作中心 |
| 楦 / 刀模 / 底模 | **到位否、套数、与款绑定**（华软等强调） | 工装夹具占用、换型矩阵 |
| 换模/换线时间 | 成型换底模分钟；裁断换料 | 换型矩阵（从 A→B 耗时） |
| 技能/人数 | 针车熟手系数（部分） | 技能矩阵、出勤 |
| 外协产能 | 外发厂日产能、加工周期（垂直强） | 可建模外协资源 |
| 静置/固化 | 胶水静置、恒温（高端宣传） | 工序最小/最大间隔 |

#### D. 物料与齐套（鞋业垂直高频）

| 参数选项 | 常见取值 | 说明 |
|----------|----------|------|
| 齐套门槛 | 未齐套禁止排 / 仅预警 / 首道齐套即可 | 对应我们 `kit_ready` 策略与确认闸门 |
| 齐套深度 | 只主料 / BOM N 层 / 全树 | 影响算料与拦截严格度 |
| 生产可用库存 | 与实仓库存分离；排单占用扣减 | 华软等强调，防两单抢同一料 |
| 在途/ETA | 预计到货后才允许开工 | 齐套日、最早开工 |
| 安全库存 / 欠料优先级 | 采购欠数优先级 | 计划与采购联动 |
| 替代料 | 允许/禁止；优先级 | 缺料时是否仍可排 |

#### E. 订单与优先级（生管天天调）

| 参数选项 | 常见取值 |
|----------|----------|
| 订单优先级 | 急单 / 常规 / 补单 / 预测；或数字优先度 |
| 客户等级 | A/B/C；VIP 强制齐套、禁止拖 |
| 交期 | 要求交期 vs 承诺交期；最迟结束时间 |
| 最早开工 | 料齐日、客户指定、锁定开工 |
| 锁定/冻结 | 已确认计划不可被自动重排挤动 |
| 分批 | 允许分批投产 / 必须一次投完 |
| 专线/禁合 | 指定产线；禁止与他单合并 |

#### F. 合批 / 成组（与排产交界，竞品常作规则）

| 参数选项 | 常见取值 |
|----------|----------|
| 合批维度 | 同款 / 同色 / 同皮料 / 同楦 / 同底模 / 同刀模 |
| 交期窗口 | 交期差 ≤ N 天或同周（集约周期小时/天） |
| 最小合批量 | 如 ≥300 双才建议合并（华软提内销按批投产） |
| 最大合批跨度 | 同组内交期最大差 |
| 合批后发货 | 生产可合、出货必须分（行业共识） |

#### G. 插单 / 重排 / 人机协同

| 参数选项 | 常见取值 |
|----------|----------|
| 插单策略 | 挤常规 / 拆分外协 / 加班消化 |
| 重排范围 | 全表重算 / 仅受影响工单增量重排 |
| 扰动最小化 | 尽量少改已锁定单 |
| 人工拖拽后 | 即时校验冲突；确认才下发 |
| 方案对比 KPI | 延期单数、负荷峰、加班工时 |

#### H. 鞋业特色（垂直多、通用 APS 要定制）

| 参数选项 | 说明 |
|----------|------|
| 混色混码排程 | 色码矩阵进计划，非单 SKU |
| 配码 BOM 用量 | 按码算料再占生产可用库存 |
| 装箱件数 / 配码约束 | 排产与后道装箱计划联动（部分） |
| 刀模配套自动排单 | 无刀模不到位不排或预警 |
| 上下工序衔接 | 裁断→针车→成型组别产能联动 |

### 9.2 竞品「PMC 常调」vs「实施配一次」

| 常调（界面旋钮） | 配一次（主数据/实施） |
|------------------|------------------------|
| 本次用交期优先还是保产能 | 工艺路线、标准工时 |
| 急单/VIP 开关 | 产线/班组档案、楦刀模台账 |
| 交期窗、是否加班排周末 | 换模矩阵、班次时刻表 |
| 未齐套能否进池 | BOM、损耗、外协周期 |
| 锁定某些单不被挤 | 设备维保日历 |

中小鞋厂若参数超过约 **8～12 个常调项**，现场往往退回 Excel——参数森林是精 APS 落不了的原因之一。

### 9.3 对照本系统（现有 → 建议）

| 参数族 | 本系统已有 | 建议近端补 | 明确后置/不做 |
|--------|------------|------------|----------------|
| 策略 | 保交期 / 保现场 / 只排齐套 | — | 成本最优求解 |
| 风险 | `tight_days` | — | — |
| 产能 | 全局/工序日产能（双/天） | — | 机台小时、开动率曲线 |
| 日历 | 国定假+调休工作日 | **非工作日是否可排**；可选厂休日 | 全量班次时刻甘特 |
| 齐套 | 池互斥、kit 策略、确认闸门 | **齐套日硬卡开工** | BOM 无限深遍历作默认 |
| 优先级 | 急单 `is_rush` | 客户等级权重（轻） | 十几种规则组合引擎 |
| 合批 | 人工 B2f | **交期窗、同色、最小量、禁合**（推荐引擎） | 换型矩阵优化器 |
| 插单 | 仿真 + 方案对比 | — | 无人全表自动落库 |
| 楦/刀模/外协 | — | B3a/B2a 后提示 | 模具独占 APS |
| 缓冲 | 隐含在工序天数 | 可选负荷上限 % 预警 | 复杂浮动时间 |

**产品取舍：** 竞品参数字典可以很长；我们对中小 OEM 只把「策略 + 日历加班 + 产能 + 齐套门槛 + 合批交期窗 + 急单」做成常调，其余进主数据或二期。
