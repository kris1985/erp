## 0. 目标 / 非目标

**目标**

1. 筐卡完工可选 **入库** 或 **直发**（`allow_direct_ship`）。  
2. 直发：虚拟入→出，净库存不变，流水完整；按 ratio 生成/关联**销售向**出货。  
3. **预装箱**挂筐/执行单 → 出货或直发时落成出货装箱 → 箱唛（逐箱/批量/补打）。  
4. 入库时人工成本按 ratio 归集到销售色码（接现有毛利/经营口径）。

**非目标**

- 重做应收核销引擎（复用现网出货→应收）  
- 排产池切主、插单重算（→ I3）  
- 产线（→ I3plus）  
- 直发瞬间空造装箱单（禁止）

## 2. 时序定稿（必须实现）

```text
包装段：按筐预装箱（明细挂 basket / execution）
    ↓
扫筐完工
    ├─ 入库 → FG++ → 筐「已入库」
    │         日后建出货：预装箱过户为出货装箱 → 打正式唛 → 应收
    └─ 直发 → 校验预装箱合计=完工双数
              → 出货单(认销售色码) + 装箱落成
              → 虚拟入出（净库存 0）
              → 筐「已出货」→ 可打唛
```
