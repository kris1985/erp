## 0. 目标 / 非目标

**目标**

1. 销售色码可进入「可产」视角；同款同色同码可合并为**一张规格执行单**，带 qty/ratio 分配。  
2. 开裁按执行单生成父卡（隐）+ 多筐多捆；筐上可印多销售来源。  
3. 报工/产量按 ratio 回写销售色码与执行单，合计勾平。  
4. 齐套/领料主体迁到执行单（迁移期映射），可产过滤接现网料池。  
5. 在制销售进度可预估；计件工资仍不拆销售单（成本归集落点可在 I2 写库）。

**非目标**

- 成品仓、直发、预装箱落成出货（→ I2）  
- 排产池彻底改色码主输入、插单重算引擎（→ I3；本迭代可手工合单）  
- 无比例硬合并、批次出货不分来源

## 2. 关键设计约束

```text
SalesOrderLineItem (需求色码)
    --allocation(qty, ratio)-->
SpecExecutionOrder (款+色+码)
    --> FlowParent (可选同表字段)
    --> Basket[] --> Bundle[]
WorkLog --> 回写 execution + 按 ratio 预估/确认销售色码产量
MaterialRequirement 挂 execution_id（迁移期可双写旧 order_id）
```

- 规格执行单：**推荐新表** + 旧 `orders` 适配期（总纲开放题 #1）。  
- 合批 `MergeBatch`：本迭代可不删；新合单路径不依赖合批账本。
