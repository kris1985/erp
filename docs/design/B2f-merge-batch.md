# B2f 设计：合批 L1+L2

> **状态：** ✅ 走查通过（2026-08-09）  
> **总纲：** [`product-roadmap.md`](../product-roadmap.md) §4.2 / §7 B2f  
> **对象：** 合批头挂多张 **生产单** `orders`；账本仍认各 `orders.id`

---

## 1. 目标与边界

**目标**  
勾选同款（默认同色）多张生产单 → 组成合批 → 成员列表 + 汇总色码 → 打印合批流转卡 → 可移出成员并重打。

**不做（§4.2）**

- 批次级领料 / 齐套互斥 / 出货  
- 默认报工自动分摊  
- 真合单（B3c）  
- 排产按批筛选（可选，本轮未做）

---

## 2. 主路径

1. `/admin/orders` 勾选 ≥2 张 →「组成合批」  
2. 默认同色校验；失败可改「允许多色」  
3. 弹窗看成员 + 汇总色码 →「打印合批卡」→ `/admin/merge-batches/print/:id`  
4. 可「移出」成员后重打  

---
