# A1c 设计：批价同类实绩

> **状态：** ✅ 走查通过（2026-08-09）  
> **总纲：** [`product-roadmap.md`](../product-roadmap.md) §7 A1c  

---

## 1. 目标与边界

**目标**  
在成品开发（报价旁）用**人话**对照：这款以前实际花多少、大概剩多少，别只看档案标准成本。

**不做**

- 不阻断保存报价 / 批量导出报价单  
- 不替代完整成本会计 / 财务决算  
- v1 不做跨款近邻聚类  

---

## 2. 口径（对内）

| 项 | 定义 |
|----|------|
| **同类（v1）** | 同一货号已出货生产单 |
| **实际花费** | `(材料+计件人工+其它)/出货双数`（估算） |
| **多半水平** | 中位数；**仅 1 单时等于该单** |
| **多数区间** | P25–P75（样本&lt;3 不展示） |
| **档案成本** | 产品物料+人工+其它标准成本 |
| **样本上限** | 最近 12 单 |

---

## 3. UI（收束）

左标签右数值：实际花费 / 档案成本 / 对照一句 / 参考（毛利·单号）。
